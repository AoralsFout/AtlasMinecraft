# Java 1.21.1 区块随机刻逐刻对照

在一块晴天区块里，移除唯一相邻原木后，橡树树叶先在第 2 刻由距离 1 变为 7，再在第 3 刻被随机抽中并消失。同一区块的一株小麦在第 5 刻从年龄 6 长到 7。这是 `continuous_clear_chunk` 的一次确定性结果。区块坐标为 `(-3, 2)`，`randomTickSpeed=3`，16 刻间持续使用同一坐标采样器和关卡随机源。树和小麦的初始位置选在这段序列会访问的格子上。[原版探针](../../tools/worldgen/probes/RandomTickLevel.java) · [逐刻记录](../../testdata/worldgen/random_ticks_1.21.1.json)

26 个场景共记录 249 个游戏刻、733 次区段坐标抽样和 8 次降水坐标抽样。每刻先应用外部编辑，再运行原版 `LevelTicks.tick` 的到期方块回调，随后调用 `ServerLevel.tickChunk`。原版执行区段筛选、随机坐标生成、方块与流体的抽样分派，以及树叶和小麦的回调。探针提供隔离区块、固定亮度和树叶空掉落表。耕地雨水场景采用对应的原版生物群系和高度图判定，其余场景为晴天。降水坐标仍按原版消耗随机数，降水处理本身留空。树叶掉落物的生成另有原版向量。[探针入口](../../tools/worldgen/probes/RandomTickProbe.java) · [树叶掉落对照](leaf_decay_1.21.1.md)

| 场景 | 逐刻观察 |
| --- | --- |
| 两片树叶与一根原木 | 第 1 刻移除原木，前两刻随机刻速度为 0。两片树叶分别在第 6、7 刻达到距离 7，在第 9、10 刻被抽中并消失。另一根原木旁的树叶和持久树叶始终保留。 |
| 含水树叶 | 同一刻先抽中距离 7 的普通含水树叶，再抽中它下方距离同为 7 的持久含水树叶。上一格变为水源，下一格保留含水持久叶。原版放置回调和相邻叶的形状回调分别在两格登记水的计划刻，轨迹结束时两个请求均在原版队列中，后续水流在本场景之外。 |
| 小麦从年龄 0 到 7 | 中心小麦下方设置 3×3 耕地，比较湿润、干燥、同行、两轴相邻及对角相邻五种布局。亮度取 8、9 和 15。对应布局分别在第 20、42、20、37、37 刻成熟。 |
| 区段遍历 | 在不同高度布置水、树叶、石头和小麦，比较实时编辑与全区段重新计数后的抽样，速度含 0、1、3 和 6。 |
| 耕地吸水与干燥 | 同高度对角四格处的水、上一层的含水树叶，以及邻接区块内的流动水均将湿度补到 7。下一层的水与水平五格外的水无效。裸耕地从湿度 2 经两次命中降到 0，第三次才变泥土。上方有小麦时，湿度 0 会保留。 |
| 雨水 | 平原露天耕地在雨中恢复到 7。平原玻璃顶下、沙漠和积雪平原的耕地继续变干。 |
| 顶部覆盖 | 上方放置石头会入队，即使随机刻速度为 0，下一游戏刻仍变为泥土。到期前移走石头会保留耕地，栅栏门不会入队。每刻比对方块与待执行的耕地请求。 |
| 同刻先耕地、后小麦 | 两个场景共用关卡种子 70、相同坐标和随机刻速度 2。第一抽命中耕地，第二抽命中其正上方的小麦。灌溉场景的湿度从 0 升到 7，小麦从年龄 0 长到 1；对照场景缺水，两项都保持 0。 |

前八个场景逐刻指定关卡随机种子。其中两叶场景在第 9、10 刻指定坐标采样器的输入，小麦场景在每刻指定输入，以便覆盖成功、失败和成熟后的抽样。第九个场景连续运行两套随机状态，含水树叶场景则记录一个完整区块随机刻。上述成熟与凋落时间仅描述各自的受控场景。

## 回放格式

`initial` 与 `edits` 的每项为 `[世界 X, 世界 Y, 世界 Z, 原版方块状态 ID]`。`initial` 按顺序写入空区块；当 `recount` 为真时，随后对所有区段调用 `LevelChunkSection.recalcBlockCounts`。每刻的 `states` 按 `initial` 的顺序给出更新后的所有状态 ID。

`lcgBefore` 和 `lcgAfter` 是关卡坐标采样器的有符号 32 位状态。`seed` 是当刻开始时可交给 `LegacyRandomSource` 构造器的种子，`rngAfter` 是结束时直接读取的 48 位内部状态。`continuous` 场景也记录等价种子，便于重放单行。`samples` 按调用顺序记录区段坐标，`precipitation` 单独记录抽中的降水坐标。降水检查先于区段抽样。

状态表每个全局状态 ID 占一个字节。从低位起依次表示方块有随机刻、流体有随机刻、流体非空、流体属于水标签，以及方块属于 `#minecraft:maintains_farmland`。原版区段在实时写入时，按流体是否非空增减流体计数；重新统计整个调色板时，按流体是否有随机刻累加出现次数。新放置的水可以使区段进入随机抽样，重新计数后仅有水的区段会被跳过。[原版状态表](../../internal/world/random_tick_states_1.21.1.bin) · [1.21.1 官方服务端映射](https://piston-data.mojang.com/v1/objects/03f8985492bda0afc0898465341eb0acef35f570/server.txt)

## 复查

将 Java 21 JDK 加入 PATH 或设置 `JAVA_HOME`，从仓库根目录运行以下命令。脚本校验 `jar/server.jar` 的官方 1.21.1 SHA-1，编译探针，并逐项核对原版轨迹和全部 26,684 个状态标记。移除 `--check` 可重建两份文件。[生成脚本](../../tools/worldgen/build_random_tick_probe.py)

```sh
python tools/worldgen/build_random_tick_probe.py --check
```
